4. Шаг 2 — Разрезка на кадры (SpriteFrames)

Создай SpriteFrames ресурс и разрежь спрайт-шит на 9 кадров. Каждый кадр — 32x32 px.

Ручной способ (через редактор)

  1. Создай SpriteFrames ресурс в папке Resources/Animations/Weapon/
  2. Открой панель SpriteFrames → Animation Frames
  3. Нажми Add frames from sprite sheet
  4. Выбери Swordaseprite.png
  5. Укажи: Horizontal: 9, Vertical: 1
  6. Готово — 9 кадров добавлены в анимацию "default"

Программный способ (GDScript)

# sword_sprite_builder.gd
# Запусти один раз для генерации SpriteFrames
func _ready() -> void:
    var texture = preload("res://Aseprites/Debug/Swordaseprite.png")
    var frames = SpriteFrames.new()
    
    # Удаляем default-анимацию, создаём свою
    frames.remove_animation("default")
    frames.add_animation("slash")
    
    # Разрезаем спрайт-шит на 9 кадров
    var frame_w = 32
    var frame_h = 32
    var total_frames = 9
    
    for i in range(total_frames):
        var region = Rect2(i * frame_w, 0, frame_w, frame_h)
        var atlas = AtlasTexture.new()
        atlas.atlas = texture
        atlas.region = region
        frames.add_frame("slash", atlas, i)
    
    # Сохраняем как .tres
    ResourceSaver.save(frames, "res://Resources/Animations/Weapon/sword_frames.tres")
    print("SpriteFrames создан!")

6. Шаг 4 — Настройка анимации

В SpriteFrames можно настроить скорость, looping и другие параметры анимации.

Скорость (FPS)
Текущая: 30 FPS. Рекомендуется: 12-24 для пикселя. Настройка через speed_scale или в SwordFrames.tres.
Looping
Атака меча — не зацикленная анимация. Включай Loop = OFF.
Сигнал finished
Используй animation_finished чтобы вернуть оружие в idle.
Скорость кадров
Для разных фаз можно менять FPS: замах медленнее, удар быстрее.
# Текущая скорость в SwordFrames.tres: 30 FPS
# Рекомендуется: 16 FPS для пиксельной анимации

# Настройка скорости в коде
sprite.speed_scale = 0.5 # замедлить в 2 раза (30 → 15 FPS)
sprite.speed_scale = 1.0 # как есть (30 FPS)
sprite.speed_scale = 1.5 # ускорить (30 → 45 FPS)

# Сигнал завершения
sprite.animation_finished.connect(_on_attack_finished)

7. Шаг 5 — Интеграция с Player

Атака вынесена в отдельный скрипт PlayerAttackController. Игрок вызывает его через @export.

# player_controller.gd
class_name PlayerController
extends CharacterBody2D

@export var move_speed : float = 2
@export var jump_force : float = -800
@export var max_jump_hold : float = 1
@export var gravity : float = 980
@export var attack_damage : float = 30

@export var attack_controller : PlayerAttackController

func _unhandled_input(event : InputEvent) -> void:
    if event.is_action_pressed("attack"):
        attack_controller.attack()
    _correct_turn()

func _correct_turn() -> void:
    if velocity.x > 0:
        set_meta("looking_left", false)
    elif velocity.x < 0:
        set_meta("looking_left", true)
# player_attack_controller.gd
class_name PlayerAttackController
extends Node

@onready var weapon_animation : AnimatedSprite2D = $"../Weapon/AnimatedWeapon"

var is_attacking = false

func _ready() -> void:
    weapon_animation.animation_finished.connect(_on_animation_finished)

func attack():
    if is_attacking:
        return
    weapon_animation.play("SwordSwingAnimation")
    is_attacking = true

func _on_animation_finished():
    is_attacking = false

9. Варианты анимаций

Из одного спрайт-шита можно создать несколько анимаций, разбив кадры по-разному.

Slash (удар)
F0-F8 → одна атака. Speed: 16 FPS. Loop: OFF.
Idle (ожидание)
F0 → статичный кадр. Без анимации. Или F0+F1+F0 как покачивание.
Charge (заряд)
F0-F2 → замах. Speed: 8 FPS. Loop: OFF. Для длинной атаки.
Quick Slash
F3-F5-F6 → быстрый удар. Speed: 24 FPS. Loop: OFF.

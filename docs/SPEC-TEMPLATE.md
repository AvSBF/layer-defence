# ТЗ: Шаблон документации Layer Defence

## Назначение

Каждая система/фича проекта документируется отдельным HTML файлом в `docs/`.

## Имя файла

`docs/{topic-name}.html`

Примеры:
- `enemy-system.html`
- `platform-system.html`
- `damage-knockback-system.html`
- `inventory-system.html`

## Структура HTML

### Обязательные секции (порядок)

| # | Секция | Описание |
|---|--------|----------|
| 1 | **Обзор системы** | Описание + SVG-диаграмма взаимодействия |
| 2 | **Структура файлов** | Дерево: какие файлы создаются/изменяются |
| 3 | **Реализация** | Фрагменты кода с подсветкой (GDScript) |
| 4 | **Параметры** | Таблица: параметры, типы, значения по умолчанию |
| 5 | **Как это работает** | Пошаговый flow через `→` стрелки |
| 6 | **Чеклист реализации** | Нумерованный список шагов для реализации |

### Опциональные секции

- **Демо** — интерактивные виджеты (HP бар, knockback, etc.) через `<script>`
- **Примеры использования** — код из реальных скриптов проекта
- **Таблица сравнения** — если есть альтернативные подходы

## SVG-диаграммы

- Минимальный размер: `width="700" height="260"`
- Фон: `#0d0d14` (внутри `.diagram`)
- Цвет линий: `#333` (связи), `{accent}` (активные)
- Шрифт: `font-size="12-14"`, `font-weight="bold"` для заголовков
- Скруглённые прямоугольники: `rx="8"` для блоков, `rx="25"` для state-машин
- Стрелки через `marker-end="url(#arrow)"`

## Интерактивные демо

- Встраиваются через `<script>` в конце файла
- CSS анимации через `transition` для плавности
- `requestAnimationFrame` для сложных анимаций
- Кнопки: стиль `.hp-btn` (фон `#222235`, бордер акцентный, текст акцентный)

## Пример色の выбора

```
1. Определи основной цвет темы (красный → бой, зелёный → платформы, синий → UI)
2. Выбери второй цвет — более светлый/тёплый вариант
3. Замени {COLOR1} и {COLOR2} во всех местах шаблона
```

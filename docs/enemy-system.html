Enemy System

Архитектура системы врагов для Layer Defence — Composition + Resource-based подход

1. Архитектура

Враг — это контейнер компонентов. Каждый компонент отвечает за свою задачу. Новые враги создаются через ресурсы (.tres), код трогать не нужно.

2. Структура файлов

Scripts/Enemies/
├── enemy.gd — главный скрипт врага
├── health_component.gd — HP, урон, смерть
├── ability_component.gd — кулдауны способностей
├── state_machine.gd — стейт-машина
├── state.gd — базовый класс состояния
├── States/
│ ├── idle_state.gd — ожидание
│ ├── chase_state.gd — погоня за целью
│ └── attack_state.gd — атака
└── Resources/
    ├── enemy_stats.gd — класс ресурса статов
    └── enemy_ability.gd — класс ресурса способности

Resources/Enemies/
├── Stats/
│ ├── tank_stats.tres
│ ├── assassin_stats.tres
│ └── ranged_stats.tres
└── Abilities/
    ├── dash_ability.tres
    ├── jump_ability.tres
    └── shoot_ability.tres

Resources/Prefabs/Enemy/
└── Enemy.tscn — сцена врага

3. Ресурсы (.tres)

EnemyStats — параметры врага

class_name EnemyStats
extends Resource

@export var max_hp : float = 100
@export var move_speed : float = 100
@export var damage : float = 10
@export var jump_force : float = -400
@export var dash_force : float = 300
@export var dash_duration : float = 0.2
@export var attack_range : float = 50
@export var attack_cooldown : float = 1.0

EnemyAbility — описание способности

enum AbilityType { DASH, JUMP, SHOOT, CHARGE, TELEPORT }

@export var ability_name : String = ""
@export var ability_type : AbilityType = AbilityType.DASH
@export var cooldown : float = 1.0
@export var damage : float = 0
@export var range : float = 100
@export var speed_multiplier : float = 1.0
@export var duration : float = 0.2

4. Типы врагов

Tank
Тяжёлый враг. Много HP, медленный, сильный удар в ближнем бою.
HP: 200 Speed: 60 DMG: 20 Range: 40
Assassin
Быстрый и смертоносный. Дэшится к цели, прыгает через платформы.
HP: 60 Speed: 180 DMG: 15 Dash: 400
Ranged
Стреляет издалека. Держит дистанцию, уворачивается.
HP: 80 Speed: 100 DMG: 10 Range: 200

5. Стейт-машина

Враг переключается между состояниями. Каждое состояние управляет поведением.

# enemy.gd
func _ready() -> void:
    if stats:
        health_component.max_health = stats.max_hp
        health_component.health = stats.max_hp
        ability_component.setup(stats)

# Спавнер (пример)
var enemy = preload("res://Resources/Prefabs/Enemy/Enemy.tscn").instantiate()
enemy.stats = preload("res://Resources/Enemies/Stats/assassin_stats.tres")
enemy.target = player
enemy.global_position = spawn_position
add_child(enemy)

7. Как добавить нового врага

  1. Создай .tres файл статов в Resources/Enemies/Stats/
  2. Задай параметры: hp, speed, damage, jump_force, dash_force
  3. Создай .tres файлы способностей в Resources/Enemies/Abilities/
  4. В спавнере укажи новый ресурс: enemy.stats = preload("res://.../new_stats.tres")
  5. Готово. Новый враг работает.

Пример нового врага — Healer

# healer_stats.tres
[resource]
max_hp = 120
move_speed = 90
damage = 5
jump_force = -350
attack_range = 150
attack_cooldown = 3.0

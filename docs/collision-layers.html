// Resources/Prefabs/Platform.tscn
Platform extends StaticBody2D
  collision_layer = 2 # живёт на слое 2 (Platform)
  collision_mask = 1 # сталкивается только с Layer 1 (Floor)
  one_way_collision = true # проходим снизу, сталкиваемся сверху
Важно: Platform не сталкивается с другими платформами (mask=1), только с полом. Игрок и враги сталкиваются с платформами через свою маску.

Drop-through
Да (через код)
// Scripts/Player/player_movement.gd
const PLATFORM_LAYER: int = 2

# Drop-through: отключаем маску слоя 2
controller.set_collision_mask_value(PLATFORM_LAYER, false)
# ...await timer...
# Включаем обратно
controller.set_collision_mask_value(PLATFORM_LAYER, true)
Как работает drop-through: При нажатии вниз + прыжок Player временно отключает collision_mask для слоя 2, проваливаясь сквозь платформу. Через небольшую задержку маска восстанавливается.

Drop-through
Да (через код)
// Resources/Prefabs/Enemy/Enemy.tscn
Enemy extends CharacterBody2D
  collision_layer = 2 # живёт на слое 2 (Platform)
  collision_mask = 3 # сталкивается с Layer 1 + Layer 2

// Scripts/Enemies/States/chase_state.gd
const PLATFORM_LAYER: int = 2

# Враг падает сквозь платформы
enemy.set_collision_mask_value(PLATFORM_LAYER, false)
# ...в конце состояния...
enemy.set_collision_mask_value(PLATFORM_LAYER, true)
Особенность: Enemy имеет collision_layer=2 (тот же слой, что и Platform). Это означает, что Enemy не сталкивается с другими врагами (их маски не пересекаются с layer 2 через mask). Враг добавляет себя в группу "enemy" в runtime.
WeaponWave
Area2D — волна оружия (_area_)
collision_layer
1 дефолт
collision_mask
3 (= 1+2)
Тип
Area2D не PhysicsBody
Детекция
get_overlapping_bodies()
// Scripts/Weapons/weapon_wave_controller.gd
# Area2D не сталкивается физически, а только детектит
var bodies = get_overlapping_bodies()
for body in bodies:
  if body.is_in_group("Enemy"):
    # нанести урон
Mask=3 означает, что WeaponWave детектит и Floor (Layer 1), и Platform/Enemy (Layer 2). В коде фильтруется по группе "Enemy".

6. Группы объектов

Группы используются для дополнительной фильтрации при обнаружении столкновений.

ГруппаОбъектыГде определенаКак используется
"platforms" Platform Platform.tscn (автоматически) Player и Enemy проверяют is_in_group("platforms") при столкновении
"Enemy" Enemy Enemy.tscn (автоматически) WeaponWave проверяет is_in_group("Enemy") для нанесения урона
"enemy" Enemy enemy.gd:17 (add_to_group()) Добавляется в runtime
"platform" — project.godot:25 Глобальная группа (пустая)
Разница: "Enemy" (с большой буквы) определена в .tscn файле. "enemy" (с маленькой) добавляется вручную в скрипте. WeaponWave использует "Enemy".

8. Light Mask (Rendering)

Light Mask — это отдельная система от collision. Используется для рендеринга освещения.

ОбъектСценаlight_maskНазначение
Camera2D World.tscn:110 3 Камера видит освещение на слоях 1+2
Не связано с физикой. light_mask влияет только на видимость света/тени в 2D-рендеринге.

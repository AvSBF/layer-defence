Spawner System

Система спавна врагов — волны, точки, зоны

1. Архитектура

Три уровня спавна: SpawnPoint (точка), SpawnArea (зона), WaveSpawner (волны). WaveSpawner управляет всем.

2. Структура файлов

Scripts/Spawners/
├── wave_spawner.gd — контроллер волн
├── spawn_area.gd — зона спавна (выбирает точку)
└── spawn_point.gd — конкретная позиция

Resources/Spawners/
├── enemy_wave.gd — ресурс одной волны
└── wave_1.tres ... wave_N.tres

Scenes/
└── World.tscn — добавляем спавнеры

3. SpawnPoint — Точка спавна

Простой Marker2D. Задаёт позицию, откуда появляется враг.

# spawn_point.gd
class_name SpawnPoint
extends Marker2D

@export var spawn_direction : Vector2 = Vector2.LEFT

func get_spawn_position() -> Vector2:
    return global_position

func get_spawn_direction() -> Vector2:
    return spawn_direction.normalized()

4. SpawnArea — Зона спавна

Содержит несколько SpawnPoint-ов. Выбирает случайный при спавне.

# spawn_area.gd
class_name SpawnArea
extends Node2D

func get_random_point() -> SpawnPoint:
    var points = get_children().filter(func(c): return c is SpawnPoint)
    if points.is_empty():
        return null
    return points.pick_random()

Структура на сцене:

SpawnArea (Node2D)
├── SpawnPoint — на левой платформе
├── SpawnPoint2 — на средней платформе
└── SpawnPoint3 — на правой платформе

5. EnemyWave — Ресурс волны

Одна волна: сколько врагов, какого типа, с какой задержкой.

# enemy_wave.gd
class_name EnemyWave
extends Resource

enum SpawnMode { AREA, POINT }

@export var enemy_scene : PackedScene
@export var stats : EnemyStats
@export var count : int = 5
@export var spawn_mode : SpawnMode = SpawnMode.AREA
@export var delay_between : float = 0.5
@export var spawn_area : SpawnArea
@export var spawn_point : SpawnPoint

Пример .tres:

# Resources/Spawners/wave_1.tres
[resource]
enemy_scene = "res://Resources/Prefabs/Enemy/Enemy.tscn"
stats = "res://Resources/Enemies/Stats/tank_stats.tres"
count = 3
spawn_mode = 0 # AREA
delay_between = 1.0

6. WaveSpawner — Контроллер

Главный скрипт. Управляет волнами, таймерами, количеством врагов.

# wave_spawner.gd
class_name WaveSpawner
extends Node2D

signal wave_started(wave_index : int)
signal wave_completed(wave_index : int)
signal all_waves_completed

@export var waves : Array[EnemyWave] = []
@export var delay_between_waves : float = 5.0
@export var auto_start : bool = true
@export var target : Node2D

var current_wave : int = 0
var enemies_alive : int = 0
var is_spawning : bool = false

func _ready() -> void:
    if auto_start:
        start_waves()

func start_waves() -> void:
    current_wave = 0
    _spawn_next_wave()

func _spawn_next_wave() -> void:
    if current_wave >= waves.size():
        all_waves_completed.emit()
        return
    var wave = waves[current_wave]
    wave_started.emit(current_wave)
    _spawn_enemies(wave)

func _spawn_enemies(wave : EnemyWave) -> void:
    is_spawning = true
    for i in wave.count:
        var spawn_pos = _get_spawn_position(wave)
        _create_enemy(wave, spawn_pos)
        if i < wave.count - 1:
            await get_tree().create_timer(wave.delay_between).timeout
    is_spawning = false

func _get_spawn_position(wave : EnemyWave) -> Vector2:
    if wave.spawn_mode == EnemyWave.SpawnMode.AREA and wave.spawn_area:
        var point = wave.spawn_area.get_random_point()
        if point:
            return point.get_spawn_position()
    elif wave.spawn_mode == EnemyWave.SpawnMode.POINT and wave.spawn_point:
        return wave.spawn_point.get_spawn_position()
    return global_position

func _create_enemy(wave : EnemyWave, pos : Vector2) -> void:
    var enemy = wave.enemy_scene.instantiate()
    enemy.stats = wave.stats
    enemy.target = target
    enemy.global_position = pos
    enemy.health_component.died.connect(_on_enemy_died)
    enemies_alive += 1
    add_child(enemy)

func _on_enemy_died() -> void:
    enemies_alive -= 1
    if enemies_alive <= 0 and not is_spawning:
        wave_completed.emit(current_wave)
        current_wave += 1
        await get_tree().create_timer(delay_between_waves).timeout
        _spawn_next_wave()

7. Как это работает

1. WaveSpawner стартует
→
2. Берёт wave[0]
→
3. Спавнит N врагов
→
4. Ждёт пока умрут
→
5. Пауза → wave[1]
# Волна 1: 3 танка, слева
# Волна 2: 5 ассассинов, справа
# Волна 3: 2 танка + 3 снайпера, обе зоны

# Враги спавнятся из SpawnArea (случайная точка)
# Каждый враг получает target = Player
# После убийства всех → пауза → следующая волна

9. Как добавить новую волну

  1. Создай .tres: Resources/Spawners/wave_N.tres
  2. Выбери EnemyScene (префаб врага)
  3. Выбери Stats (тип врага)
  4. Задай count — сколько врагов
  5. Выбери SpawnArea или SpawnPoint
  6. Добавь .tres в массив waves на WaveSpawner
  7. Готово

10. Диаграмма потока

11. Итого

SpawnPoint
Marker2D. Одна точка на платформе.
SpawnArea
Контейнер точек. Выбирает случайный.
EnemyWave
.tres: тип врага, кол-во, задержка, зона.
WaveSpawner
Контроллер. Запускает волны по очереди.
Масштабирование: Новые волны = новые .tres. Новые зоны = новые SpawnArea с детьми-точками. Код не трогаем.

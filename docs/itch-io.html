1. Пошаговая загрузка

  1. Create new project → заполнить Title / URL / Classification (см. таблицу ниже).
  2. Edit game → Uploads → перетащить build/layer-defence-web.zip.
  3. После загрузки у файла поставить галочку «This file will be played in the browser».
  4. itch попросит выбрать Kind of project → HTML (появится после галочки), и покажет Embed options.
  5. В Embed options: viewport 1280 x 720, включить Fullscreen button, выключить Mobile friendly и Automatically start on page load.
  6. Cover image → загрузить docs/itch/cover-630x500.png.
  7. Screenshots → загрузить 4 файла в порядке 1→4.
  8. Genre, Tags, Release status, Pricing → по таблицам ниже.
  9. More information (большое описание) → вставить готовый блок текста, при желании дополнить таблицей управления.
  10. Save & view page → проверить, что игра запускается, затем Publish (или оставить Draft до финальной проверки).
Важно: все 9 файлов сборки должны лежать в корне zip-архива, а не внутри папки. Если зазиповать папку целиком, itch выдаст «The package is missing an index.html». Наш архив уже собран правильно — при пересборке используйте команду из раздела 5.

4. Теги и метаданные

itch разрешает до 10 тегов. Предлагаемый набор (сначала самые важные):

roguelike pixel-art arena-shooter waves action survival boss-battle upgrades 2d singleplayer

Почему так: «roguelike» и «pixel-art» дают основной трафик из поиска itch, «waves» и «arena-shooter» точнее описывают жанр, «boss-battle» часто ищут отдельно. Тег «godot» ставить не обязательно — он не про игру, а про инструмент.

5. Сборка: как пересобрать и что внутри

Команда экспорта

# 1. импорт ресурсов (обязательно после правок арта) godot --headless --import --path . # 2. веб-сборка (использует export_presets.cfg, пресет "Web") godot --headless --path . --export-release "Web" "build/web/index.html" # 3. zip, где файлы лежат в КОРНЕ архива (иначе itch не найдёт index.html) # Windows PowerShell: Compress-Archive -Path "build/web/*" -DestinationPath "build/layer-defence-web.zip" -Force # или любым архиватором: выделить СОДЕРЖИМОЕ build/web и заархивировать

Состав сборки (проверено на 4.7.1)

ФайлРазмерНазначение
index.html8 KBоболочка страницы
index.js270 KBзагрузчик и связка с движком
index.wasm37.7 MBсам движок (сжимается до ~10 MB в zip)
index.pck0.47 MBвся игра: сцены, спрайты, звук, шрифт
index.audio.worklet.js<1 KBзвук вне главного потока
index.audio.position.worklet.js<1 KBпозиционный звук
index.icon.png / index.apple-touch-icon.png / index.png~30 KBиконки для вкладки и PWA

Итого: 38.5 MB распакованных, 10.1 MB в zip, ~9 MB отдаётся по gzip — страница грузится на обычном соединении 5–15 секунд.

Что настроено в пресете и почему

ОпцияЗначениеЗачем
variant/thread_supportfalseГлавное. Без threads не нужны заголовки COOP/COEP, которых itch.io не отдаёт. Проверено: в index.wasm нет pthread_create и SharedArrayBuffer. Если включить threads — игра падает с ошибкой про SharedArrayBuffer.
vram_texture_compression/*falseпиксель-арт хранится без сжатия (lossless), транскодеры Basis/ETC2 не нужны → сборка легче
html/canvas_resize_policy2 (adaptive)игра подстраивается под размер iframe на странице itch
html/focus_canvas_on_starttrueклавиатура сразу работает, без клика по канвасу
html/export_icontrueиконка вкладки
progressive_web_app/enabledfalsePWA не нужна, меньше файлов
Проверка перед загрузкой: распакуйте zip в отдельную папку и откройте её локальным сервером — игра должна запуститься без консольных ошибок:
# из папки с распакованными файлами python -m http.server 8000 # затем http://localhost:8000/ в Chrome/Firefox

6. Если что-то пошло не так

СимптомПричинаРешение
itch пишет «The package is missing an index.html»файлы зазипованы в папкупересобрать zip так, чтобы index.html лежал в корне архива
Файл не играется в браузере, только скачиваетсяне отмечена галочка «This file will be played in the browser»поставить галочку в Uploads
Чёрный экран, в консоли SharedArrayBuffer is not definedсборка с threadsэкспортировать с variant/thread_support=false (в нашем пресете уже так)
Чёрный экран без ошибокне дождались загрузки / кэшподождать 10–20 секунд, обновить страницу с Ctrl+F5, проверить в другом браузере
Нет звукаполитика автоплея браузерову нас «Automatically start on page load» выключен: звук включается после первого клика игрока — так и задумано
Мышь «уезжает» из канвасакурсор меняется на игровой (crosshair)это нормально; в полноэкранном режиме (кнопка на itch) проблемы нет
Управление не реагируетфокус не на канвасекликнуть один раз по игровому полю (плюс у нас focus_canvas_on_start)
Игра тормозитслабый GPU / много врагов на 12-й волнепредупредить об этом в описании: «лучше всего работает в Chrome/Edge/Firefox последних версий»
Мобильные: сборка технически откроется на телефоне, но игра требует мышь и клавиатуру. Обязательно выключите Mobile friendly, иначе itch покажет её в мобильной ленте и получит злые отзывы.

8. Что стоит проверить перед публикацией в самой игре

  • Баланс первых трёх волн — самый важный участок для отзывов: сейчас 6 HP, обычные враги бьют на 1, босс на 5-й волне имеет ~525 HP.
  • Если игра окажется слишком тяжёлой, самые быстрые ручки: GameState.reset_run() (max_health = 6), WaveManager.elite_chance() и EnemyCatalog (поле weight у врагов регулирует состав волн).
  • Проверьте производительность на 12+ волне: там 10–15 врагов и до 30 снарядов одновременно.
  • Звук на веб-сборке звучит тише, чем в редакторе (мастер −8 дБ) — при необходимости поднять в audio.gd.

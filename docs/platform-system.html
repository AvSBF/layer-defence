Platform System

Система платформ для Layer Defence — односторонние платформы, проваливание, collision layers

1. Архитектура

Система платформ использует Collision Layers для разделения физики пола и платформ. Платформы — односторонние (one-way), через них можно прыгнуть снизу, но можно провалиться сверху.

2. Collision Layers

Godot использует битовые маски для определения столкновений. Каждый объект имеет collision_layer (где он находится) и collision_mask (с чем проверяет столкновения).

LayerНазначениеОбъекты
1 Пол / статичные объекты Floor, Border
2 Платформы (односторонние) Platform (все платформы)

Настройка врагов

# Enemy.tscn
collision_layer = 2 # Враг на layer 2
collision_mask = 3 # Столкновения с layer 1 + 2
⚠️ Важно
Если у врага collision_mask = 1, он не будет коллизиться с платформами (layer 2). Всегда проверяй mask!

3. Односторонние платформы

Платформы используют one_way_collision = true. Это значит:

Снизу вверх
Можно прыгнуть сквозь платформу. Тело проходит насквозь и встает сверху.
Сверху вниз
Нельзя пройти сквозь платформу. Тело стоит на ней как на полу.

Platform.tscn

[node name="Platform" type="StaticBody2D" groups=["platforms"]]
collision_layer = 2
collision_mask = 1

[node name="CollisionShape2D" type="CollisionShape2D" parent="."]
shape = SubResource("RectangleShape2D_xxx")
one_way_collision = true # Ключевая настройка!
💡 Совет
Односторонние платформы автоматически пропускают тела снизу. Но если нужно провалиться сверху — нужна дополнительная логика (см. раздел 4).

4. Проваливание сквозь платформы

Механика "drop-through" — игрок нажимает вниз и проваливается сквозь платформу. Используется во многих платформерах.

1. Игрок на платформе
→
2. Нажал key_down
→
3. Отключаем collision с layer 2
→
4. Игрок проваливается
→
5. Через 0.2с включаем обратно

Реализация в player_movement.gd

const DROP_DURATION : float = 0.2
const PLATFORM_LAYER : int = 2

var is_dropping : bool = false
var drop_timer : float = 0.0

func _physics_process(delta: float) -> void:
    # ... горизонтальное движение ...

    if not controller.is_on_floor():
        controller.velocity.y += controller.gravity * delta
    elif Input.is_action_just_pressed("key_down") and _is_on_platform():
        _start_drop() # Начинаем проваливание

    if is_dropping:
        drop_timer -= delta
        if drop_timer <= 0:
            _end_drop() # Включаем коллизию обратно

    controller.move_and_slide()

Проверка — стоит ли на платформе

func _is_on_platform() -> bool:
    for i in range(controller.get_slide_collision_count()):
        var collision = controller.get_slide_collision(i)
        var collider = collision.get_collider()
        if collider.is_in_group("platforms"):
            return true
    return false

Включение/отключение коллизии

func _start_drop() -> void:
    is_dropping = true
    drop_timer = DROP_DURATION
    controller.set_collision_mask_value(PLATFORM_LAYER, false)

func _end_drop() -> void:
    is_dropping = false
    controller.set_collision_mask_value(PLATFORM_LAYER, true)
⚠️ Почему не через пол?
Пол не находится в группе "platforms". Поэтому проверка _is_on_platform() вернет false, если игрок стоит на полу. Провалиться через пол невозможно.

5. Враги и платформы

Враги тоже проваливаются сквозь платформы, когда преследуют игрока на той же платформе.

Логика в chase_state.gd

func physics_process(delta : float) -> void:
    # ... погоня за целью ...

    # Если враг на платформе И игрок ниже — проваливаемся
    if enemy.is_on_floor() and _is_on_platform() and _is_on_same_platform() and to_target.y > 20:
        _start_drop()

Проверки

func _is_on_platform() -> bool:
    for i in range(enemy.get_slide_collision_count()):
        var collision = enemy.get_slide_collision(i)
        var collider = collision.get_collider()
        if collider.is_in_group("platforms"):
            return true
    return false

func _is_on_same_platform() -> bool:
    if not enemy.target:
        return false
    return enemy.target.global_position.y > enemy.global_position.y
💡 Как работает
Враг проверяет: "Я на платформе?" + "Игрок ниже меня?". Если оба условия выполнены — враг проваливается, чтобы преследовать игрока. Расстояние > 20px чтобы не проваливаться сразу.

6. Группа "platforms"

Все платформы добавлены в группу "platforms". Это позволяет:

Определять платформы
Функция _is_on_platform() проверяет группу через is_in_group("platforms")
Исключать пол
Пол не в группе "platforms", поэтому через него нельзя провалиться

Добавление в группу

# В Scene Tree: ПКМ на ноде → Add to Group → "platforms"
# Или в коде:
add_to_group("platforms")
